# Archived eval results — xLAM-2-3b-fc-r

Every run in this directory was measured against `xLAM-2-3b-fc-r-q4_0.gguf`,
a model no longer used in this repo. The numbers below are real measurements
and are kept for eval-methodology history (tool ordering, schema-diet
token counts, constrained-decoding accuracy deltas) — they are not
representative of the repo's current model (Qwen2.5-3B-Instruct) and must
not be read as such. New eval runs go in `eval/results/` as before.
